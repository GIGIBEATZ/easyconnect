═══════════════════════════════════════════════════════════════════════════════
                           DATABASE SCHEMA
═══════════════════════════════════════════════════════════════════════════════

4 NEW TABLES CREATED:

1. agent_pricing_profiles
   Stores agent pricing information
   • agent_id → links to agent profile
   • hourly_rate (e.g., $50 = 5000 cents)
   • minimum_charge (minimum billable amount)
   • allows_negotiation (boolean flag)
   • description (agent's pricing notes)

2. price_proposals
   Tracks all price quotes
   • agent_id → who sends the proposal
   • client_id → who receives it
   • breakdown → itemized services (JSON)
   • total_price → final cost
   • status → draft/sent/counter/accepted/rejected
   • expires_at → when offer expires

3. price_negotiation_history
   Audit trail of all offer/counter-offer interactions
   • proposal_id → which proposal
   • from_user_id → who made the offer
   • to_user_id → who received it
   • action → proposed/countered/accepted/declined
   • proposed_amount → the amount offered
   • timestamps → when action occurred

4. agreed_pricing
   Final locked price for each ticket
   • ticket_id → links to support ticket
   • final_price → locked price (cannot change)
   • breakdown → itemized breakdown
   • agreed_by_agent_at → when agent confirmed
   • agreed_by_client_at → when client confirmed

═══════════════════════════════════════════════════════════════════════════════
                            HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════════

SIMPLE 6-STEP WORKFLOW:

STEP 1: CLIENT BROWSES
• Visit "Find Agents"
• See agent profiles with pricing visible
• $50/hour, $25 minimum charge displayed

STEP 2: CLIENT CLICKS "GET PRICE QUOTE"
• Describes the problem
• Requests estimate

STEP 3: AGENT SENDS PROPOSAL
• Creates itemized quote:
  ├─ Diagnosis: $25
  ├─ Labor (2 hours): $100
  ├─ Parts: $50
  └─ Total: $175
• Sets expiration (24 hours)
• Sets payment terms

STEP 4: CLIENT REVIEWS & DECIDES
Option A: ACCEPT → Price locked, go to step 6
Option B: COUNTER → "Can you do $120?" (go to step 5)
Option C: REJECT → Find other agent

STEP 5: NEGOTIATION (if counter-offered)
• Chat interface
• Back-and-forth offers
• Timestamps recorded
• Full history tracked
• Until agreement reached

STEP 6: FINAL CONFIRMATION
• Review final price: $135
• Both parties confirmed
• Create support ticket
• Price locked - cannot change
• Work begins
