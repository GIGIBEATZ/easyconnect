                            DATABASE TRANSACTIONS
════════════════════════════════════════════════════════════════════════════════

Event Timeline:

1. Browse Agents
   └─→ SELECT * FROM agent_pricing_profiles

2. Agent Sends Proposal
   └─→ INSERT INTO price_proposals (status: 'sent')
   └─→ INSERT INTO price_negotiation_history (action: 'proposed')

3. Client Counters
   └─→ UPDATE price_proposals (status: 'counter_offered')
   └─→ INSERT INTO price_negotiation_history (action: 'countered')

4. Agent Accepts Counter
   └─→ UPDATE price_proposals (status: 'accepted')
   └─→ INSERT INTO price_negotiation_history (action: 'accepted')

5. Create Ticket
   └─→ INSERT INTO support_tickets (agreed_price: 13500)
   └─→ INSERT INTO agreed_pricing (final_price: 13500)
   └─→ UPDATE price_proposals (ticket_id: set, status: 'finalized')

Storage Format:    Display Format:        SQL Value:
──────────────────────────────────────────────────

Calculation Example:
    Agent hourly rate: $50/hour (5000 cents)
    Hours estimated: 2 hours
    Labor cost: 5000 * 2 = 10000 cents = $100
